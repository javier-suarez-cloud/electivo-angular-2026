## Cómo ejecutar un proyecto

Cada actividad contiene su propio proyecto Angular. Para ejecutarlo:

```bash
cd Actividades/Actividad1/actividad1
npm install
ng serve --open
```

La carpeta `node_modules` no se sube al repositorio; `npm install` la vuelve a crear.
